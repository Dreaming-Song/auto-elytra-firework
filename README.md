# Auto Elytra Firework(鞘翅烟花自动加速)

一个面向 **Minecraft 26.2 + Fabric** 的纯客户端模组:鞘翅滑翔时按 **空格**(默认键,可在 选项 -> 控制 -> 移动 中修改)自动从玩家背包里取用烟花火箭加速;使用结束后**原手持物品会立刻被放回原位**,不需要把烟花放到手上。

> 环境要求:MC 26.2、Fabric Loader ≥ 0.19.2、Java 25;依赖 Fabric API、Mod Menu、Cloth Config(模组文件夹里已随模组菜单一并提供即可)。

---

## 功能与设置

模组菜单入口:Mod Menu 模组列表中点击本模组的“配置”。

| 设置 | 默认值 | 说明 |
|---|---|---|
| 启用自动加速 | 开 | 总开关 |
| 同时响应原版跳跃键 | 关 | 开启后,鞘翅飞行时按游戏自带的空格/跳跃键也会触发;关闭时只认模组按键 |
| 开始滑翔的那一次按键不立即使用烟花 | 开 | 操作节奏:第一下空格跳跃 → 第二下空格进入鞘翅滑翔 → 第三下空格用烟花;关闭后第二下滑翔同时也会加速 |
| 使用间隔 | 10 刻 | 两次自动使用之间的最小间隔(20 刻 = 1 秒) |
| 使用无爆炸效果的烟花 | 开 | 只含火药、不带烟花星的普通火箭,不会在身旁炸开 |
| 使用带爆炸效果的烟花 | 关 | 含烟花星、会爆炸的火箭,默认不使用 |
| 飞行时间 1/2/3 | 全开 | 按火药数量(1/2/3)细分是否允许自动使用 |
| 副手中的烟花也可自动取用 | 开 | 可临时借用副手烟花,用完放回副手 |
| 优先使用副手中的烟花 | 开 | 副手有可用烟花时先于背包其它位置使用,用完仍放回副手 |
| 保留烟花数量 | 1 | 背包中可用烟花总数不超过该值时一叠都不动(主手、副手这两个“主动使用位”不受限),避免把最后的备用烟花用光 |
| 优先使用顺序 | 飞行时间长优先 | 还有其它可选:飞行时间短优先、堆叠数量多/少优先、按物品栏顺序(手持栏优先) |

按键默认绑定为 **空格**,与跳跃键相同;在“控制”界面可以改成任意键。开启“同时响应原版跳跃键”后,两种方式都可以触发。

> 触发方式为**每次新按下**:只有松开后再按下才会发射,没有“按住长按连发”。建议节奏:跳跃(松) -> 再按进入滑翔(松) -> 再按使用烟花。
>
> 系统在按住按键时产生的重复按键事件也会被忽略,因此“按住不放”不会误发射。

## 实现原理(简述)

1. 玩家处于 `isFallFlying()` 且按下加速键时,从全部背包格(含副手,可关闭)按设置过滤出候选烟花。
2. 借助 26.2 的容器输入接口,把选中烟花与**当前手持格**短暂对调。
3. 通过原版 `useItem` 网络路径发射烟花(与手动右键使用走同一套服务端校验)。
4. 立刻把原手持物品换回原位。

因此:

- 可用烟花不需要在主手或快捷栏,背包任意位置均可;
- 使用后不改变手持物品选择,物品也放回原格;
- 飞行中短暂换手约一两个 tick,视觉上只有轻微闪烁,这是纯客户端方案换取“全背包可用”的代价。

## 安装

直接把构建出的 `build/libs/auto-elytra-firework-1.0.1.jar` 放入客户端 `mods/` 文件夹。若使用工作区里的 `upgrade_26_2/client_mods_26_2/`,可复制到该目录:

```bash
cp build/libs/auto-elytra-firework-1.0.1.jar ../../upgrade_26_2/client_mods_26_2/
```

需要同时装有:

- `fabric-api-0.159.0+26.2.jar`
- `modmenu-20.0.1.jar`
- `cloth-config-26.2.155.jar`

这三者都已包含在 `upgrade_26_2/client_mods_26_2/` 完整包中。

## 自行构建

需要 JDK 25(MC 26.2 强制要求)。

```bash
./gradlew build
```

产物:

- `build/libs/auto-elytra-firework-1.0.1.jar` —— 模组本体(含模组图标)
- `build/libs/auto-elytra-firework-1.0.1-sources.jar` —— 源码包

配置文件保存在游戏目录 `config/autoelytra.json`,可直接手改,也可以在模组菜单里修改。
